# Imagens das notícias

As páginas procuram as imagens **primeiro aqui**, nesta pasta. Se o arquivo não
existir, elas tentam uma vez o endereço antigo (`psindce.org.br/ws/media-library/…`,
guardado em `data-remoto` no HTML) e, se também falhar, mostram uma placa verde da
marca no lugar — o leiaute não quebra e não aparece ícone de imagem quebrada.

Para as fotos voltarem a aparecer, basta salvar os arquivos abaixo nesta pasta,
com exatamente estes nomes:

| Arquivo                          | Onde aparece                                   |
|----------------------------------|------------------------------------------------|
| `sug-132022---piso-e-jornada.png`| Destaque do piso salarial / jornada de 30h     |
| `edital-publicado.jpg`           | Eleições PSINDCE 2024 — edital                 |
| `filiacao-2024-b.jpg`            | Campanha associativa 2024                      |
| `campanha-filiacao-2.jpg`        | Pautas da campanha (jornada, piso, trabalho)   |
| `convite-psindce.jpg`            | Convite para as assembleias                    |
| `esperancar.jpg`                 | "Os representantes sozinhos não fazem a luta"  |

Recomendações: no máximo ~1600px de largura, JPG de qualidade 80 (ou PNG quando
houver texto/arte chapada) e menos de 300 KB por arquivo.

Depois de salvar, nenhum HTML precisa ser alterado.
